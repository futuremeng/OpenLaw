# 使用说明（面向使用者）

本文只回答四件事：**这个工具能做什么、不能做什么、数据从哪来、出了问题怎么办**。
它不讲技术实现；技术口径见 `docs/design-ui-language.md` 与各设计文档。

> ⚖️ 本工具输出的都是**辅助参考**，不构成法律意见。最终判断由人作出。

---

## 一、它能做什么

| 你想做的事 | 在哪里做 | 你会得到什么 |
|---|---|---|
| 不知道哪部法规管这事 | 「关键词检索」 | 命中的条文与所属法规；点进去看原文 |
| 知道大概范围，想收窄 | 「按条件筛选」 | 按效力等级、法域、复核状态、公布年代、地区组合定位法规 |
| 知道条文大概长什么样，想找出来 | 「条文检索」 | 全库条文的逐字命中（按语料原样给出，不重排序） |
| **手头有一段引用，想知道站不站得住** | 「核验引用」 | 认出的要素、与官方留证原文的比对结论、下一步该做什么 |
| 想知道本机数据到什么程度 | 「维护法规库 → 库总览」 | 收录多少、哪些还没复核、常用法规清单的进度、数据从哪来 |

**核验引用**是这个工具的核心动作。把判决书、合同或备忘录里的一句话原样贴进去，
例如：

> 依据《中华人民共和国民法典》第五百八十四条（2021年1月1日施行）：当事人一方不履行合同义务……

系统会认出其中的法规名称、条款号与引用时点，找到本机留证的对应版本原文，逐字比对，
然后告诉你结论。**你不需要自己把它拆成四个字段。**

核验只会给出下面六种结论之一，每一种都会说明下一步：

- **引用正确**——条文找到，文字与留证原文一致；
- **文字不一致**——条文找到了，但你手头的文字与原文有出入，以原文为准；
- **未找到对应条文**——法规名、时点或条号有一项对不上，会说明是哪一项；
- **同名法规需人工确认**——库里有多部同名法规，系统不自动采信任何一部；
- **所引版本已失效**——给出当前现行版本，提示核对新条号；
- **来源链有断点**——此时**不给结论**，只告诉你去哪里补齐留证原文。

## 二、它不能做什么

- **不替你作法律判断。** 它不判定法规之间的废止与修改关系，不推测胜诉概率，
  不给出「本案应当如何」的结论。
- **不猜。** 认不出法规名就说认不出；库里没有就说没有；同名多法一律交给人确认。
- **不改写原文。** 检索结果按语料原样给出，不做同义改写、不做语义扩展、不重排序。
- **不联网。** 默认完全离线。只有你按下「获取最新法规」「刷新官方目录」这类按钮时
  才会发起网络请求，且速度受官方可接受范围的护栏限制。
- **不上传任何东西。** 运行过程中产生的记录（检索了几次、核验了几次）只存在你这台
  机器上，且**只记次数与结论，不记你搜了什么词、核验了哪条引用、办什么案子**。

## 三、数据从哪来，凭什么信

- 法规原文获取自国务院「国家行政法规库」「国家规章库」等官方渠道，每一条都保留
  **原文链接、获取时间与文件哈希**，可以逐字核对。
- 每一条数据都有**复核状态**：
  - **已复核确认**——已有人（或达到把握门槛的智能审核）与原文比对过；
  - **尚未复核**——原文已入库留证，但还没经过比对确认。**引用前请以官网文本为准。**
- 「库总览」里的**复核兑现**告诉你两件事：常用法规参考清单里已收录多少部、已复核多少部；
  本机全部条文里已复核的占比。清单由本项目按实务高频领域整理，**不是官方认定**，
  也不代表清单里的法规更重要——它只是一个可以核对的进度尺。
- 数据以更新包形式分发时带**签名与来源**：来源不在受信发布者名单里的包不会被导入。

## 四、出问题怎么办

| 现象 | 怎么办 |
|---|---|
| 搜不到东西 | 换更短的词；到「按条件筛选」确认这部法规是否在本机；确实没有就用「获取最新法规」补齐 |
| 核验说「认不出法规名称」 | 补上法规全称或带书名号的名称；不确定是哪部时先到「条文检索」找到条文再回来核对 |
| 核验说「同名法规有多部」 | 改用完整名称（含制定机关或发文字号），或补上引用时点后重试 |
| 提示「来源链有断点」 | 到「维护法规库 → 库总览」运行数据自检，按断链清单补齐留证原文 |
| 界面显示「本机数据已从格式版本 X 升级到 Y」 | 这是正常升级留痕；升级前系统已自动备份，备份路径在同一行给出 |
| 界面显示「本机尚未记录使用情况」 | 正常——记录从数据格式 v10 起才开始累计，此前没有可回溯的历史 |

## 五、两个版本

- **数据维护版**（默认）：包含人工复核、地域标引、从官方渠道逐条获取与数据自检。
  适合负责维护本机法规库的人。
- **只读查询版**：`openlaw-desktop -edition reader`。只保留查法规与取数
  （安装官方数据包、导入他人分享的更新包），不提供复核与采集的入口。
  适合只需要查的同事——**少一个入口，就少一次误改数据的机会**。
